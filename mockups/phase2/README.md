# Phase 2 mockups

Two static design directions, each with a home page and a hero page.

- `a-home.html`, `a-hero.html`, `a.css`: Direction A, "Marquee"
- `b-home.html`, `b-hero.html`, `b.css`: Direction B, "Line map"
- `mock.js`: shared helpers (tier badge, range bar, trend line)
- `data.js` / `data.json`: a real snapshot of the Deadlock API taken through the site's own code. No invented numbers.

To view: run `npm run dev` and open `/mockups/phase2/a-home.html`.
Add `?theme=king` for the Hidden King theme and `?fonts=valve` for Valve's fonts.

These are throwaway pages for choosing a direction. They are not part of the app build.
